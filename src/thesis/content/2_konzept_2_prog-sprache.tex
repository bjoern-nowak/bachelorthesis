\section{Auswahl der Programmiersprache}\label{sec:auswahl-der-programmiersprache}


Mit der Wahl des Verfahrens grenzt sich, im allgemeinen und stark im speziellen, die Auswahl möglicher Programmiersprachen für die quelloffene Software ein.
In den nachfolgenden Kapiteln werden zunächst die populärsten Frameworks für \Abk{ASP} und ihre unterstützten Programmiersprachen vorgestellt und anschließend, unter Beachtung der Rahmenbedingungen/Herausforderungen der quelloffenen Software, bewertet und ausgewählt.

Wrapper- und High-Level-\Abk{API}s (dritter), welche diese Frameworks für weitere Programmiersprachen verfügbar machen oder die Nutzung vereinfachen, werden nicht beachtet.
Diese würden eine weitere Komplexitäts- und Abhängigkeitsschicht bringen, welche im Kontext von langlebiger und wartungsarmer quelloffener Software ein größerer Nachteil ist, als die erlangten Vorteilen.
Wenn es \zB relevante Updates des eigentlichen Frameworks gibt aber diese \textquote{Zwischen-\Abk{API}s} dieses Update nicht unterstützt, so wäre man in der Entwicklung blockiert.
Noch kritischer ist dieser Fall, wenn diese \textquote{Zwischen-\Abk{API}s}, welche zumeist ebenfalls quelloffene Software sind, nicht mehr gewartet wird und man somit gezwungen ist, diese selbst zu warten oder sie auszubauen, was in beiden Fällen zu erheblichen Mehraufwand führen würde.
Beispiele sind Clorm\Note{\url{https://github.com/potassco/clorm}}, Clyngor\Note{\url{https://github.com/Aluriak/clyngor}} (Nachfolger von PyASP\Note{\url{https://github.com/sthiele/pyasp}}), Asp4J\Note{\url{https://github.com/hbeck/asp4j}}.

\subsection{Unterstützte Programmiersprachen}\label{subsec:unterstutzte-programmiersprachen}

\begin{description}
    \item[Python] ist eine hochlevel-Programmiersprache, die ursprünglich von Guido van Rossum im Jahr 1989 entwickelt wurde.
    Sie hat sich seitdem zu einer der am häufigsten verwendeten Sprachen in der Wissenschaft, Datenanalyse, künstlicher Intelligenz und Webentwicklung entwickelt.
    Eines der wichtigsten Merkmale von Python ist seine Lesbarkeit und Schreibbarkeit, die es Entwicklern ermöglicht, ihre Codezeilen einfacher und verständlicher zu gestalten.
    Es verwendet eine natürliche und lesbare Syntax, die ähnlich wie Englisch ist, was es erleichtert, den Code zu verstehen und zu pflegen.
    Python ist eine interpretierte Sprache, was bedeutet, dass der Code nicht vor der Ausführung kompiliert werden muss.
    Dies ermöglicht es Entwicklern, schnell Änderungen am Code vorzunehmen und zu testen, ohne dass ein langwieriger Kompilierungsprozess erforderlich ist.
    Ein weiteres wichtiges Merkmal von Python ist seine Dynamik.
    Es ermöglicht es Entwicklern, Variablen und Datentypen während der Laufzeit des Programms zu ändern, anstatt sie zu kompilieren und zu deklarieren.
    Dies erleichtert die Entwicklung von Prototypen und ermöglicht es, flexibler auf Änderungen im Code zu reagieren.
    Python hat auch eine große und aktive Community, die eine Vielzahl von Bibliotheken und Modulen bereitstellt, die Entwicklern das Schreiben von Code erleichtern und die Entwicklung von Anwendungen beschleunigen.
    Beispiele für solche Bibliotheken sind NumPy und Pandas für Datenanalyse, TensorFlow für künstliche Intelligenz und Django für Webentwicklung.
    Insgesamt ist Python eine vielseitige und leistungsfähige Programmiersprache, die sich sowohl für Anfänger als auch für erfahrene Entwickler eignet und in einer Vielzahl von Anwendungen eingesetzt werden kann.
    Es erleichtert die Entwicklung von Code durch seine lesbare und schreibbare Syntax, die Dynamik und die Verfügbarkeit von Bibliotheken und Modulen.
    \Vgl{PYTHON-Oliphant2007,PYTHON-Millman2011,PYTHON-Jaworski2021}

    \item[C] ist super duooper.
\end{description}
